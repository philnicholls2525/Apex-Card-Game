Base, Green, Blue, APEX and Red all use the same player master. Green, Blue and Red layer a shared border over it. APEX layers the shared purple effect and purple frame over it. Do not add baked player-specific parallel copies: the shared-layer system is what guarantees an identical photo, crop, text and badge position across all five variants.

All finished portrait masters are 1000 × 1400 pixels (5:7).
